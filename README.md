# Medleser

**Medleser** er et gratis Windows-program som leser opp PDF-, Word-, EPUB- og tekstfiler. Du ser teksten på skjermen, og ordet som leses blir markert. Lyden kan lagres som MP3.

Medleser er laget for studenter med dysleksi og andre lesevansker, men alle kan bruke det. Med de gratis stemmene lages lyden på din egen datamaskin, og dokumentene sendes ikke noe sted.

## Last ned

**[Last ned Medleser for Windows](https://github.com/magnus-nohr/medleser/releases/latest)**. Velg `Medleser-Setup-<versjon>.exe` under **Assets**.

- [Installasjonsveiledning](Medleser/veiledninger/Installasjonsveiledning.md)
- [Brukerveiledning](Medleser/veiledninger/Brukerveiledning.md)

Begge veiledningene finnes også som PDF ved nedlastingen og i Start-menyen etter installasjon.

Krever Windows 10 eller 11 (64-bit). Du trenger ikke administratorrettigheter.

## Hovedfunksjoner

- PDF (også skannet, med tekstgjenkjenning), Word, EPUB og tekst
- Hopper over sidetall, topptekst, nettadresser, fotnotetall og annet som forstyrrer
- Gratis lokale stemmer på norsk, engelsk, svensk og dansk
- Medlesing med ordmarkering, hastighet 0,75–2× og tilpasset lesevisning (blant annet OpenDyslexic og Lexend)
- Lagring som MP3, hele dokumentet eller ett kapittel per fil
- Frivillig: svært naturlige stemmer fra ElevenLabs med egen konto
