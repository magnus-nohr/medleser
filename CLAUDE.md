# Lydbok app

Prosjektet er Windows-appen Medleser i mappen `Medleser/`. Les `Medleser/STATUS.md` først. Den viser hva som er ferdig og hva som gjenstår.

- Kjør tester med `Medleser\.venv\Scripts\python.exe -m pytest -q`. Arbeidsmappen må være `Medleser`.
- Ikke gjør betalte API-kall (ElevenLabs) uten uttrykkelig godkjenning fra brukeren.
- Brukergrensesnittet og dokumentasjonen skal være på norsk bokmål.
